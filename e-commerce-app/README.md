# SneakIn Frontend

The React 19, Vite and TailwindCSS client for [SneakIn](../README.md).

```bash
npm install
npm run dev
```

The app reads the API base URL from `VITE_API_URL`, and falls back to a local
backend when it isn't set.

| Command | Purpose |
|---------|---------|
| `npm run dev` | Start the dev server |
| `npm run build` | Build for production |
| `npm run lint` | Run ESLint |
| `npm run preview` | Preview the production build |
